NeuroPlatform UI

NeuroPlatform was brain training software and simulator used by professional athletes, with targeted healthcare applications.

NeuroPlatform UI was designed as a hub with a home page built from highly modular, swappable widgets. Widgets could be added or removed depending on the audience, which made it easier to work with specific user groups and showcase new or in-progress experiences.

Responsible for

  • Helped architect the entire UI system and visual feel of the platform across mobile, PC, and VR
  • Designed the modular, swappable widget system behind the hub home page
  • Designed the platform’s pages, including stats tracking and progression pages
  • Designed in-game interfaces
  • Designed the game experience launching system
  • Designed the create-your-own custom training module experience

The NeuroPlatform UI was entirely concepted, designed, and created by myself.  Final implementation was a collaboration between myself and other Unity developers.  There are a lot of moving parts to our app, so we needed to come up with a UI that was both simplistic as well as highly flexible, since this would be the front end wrapper for most, if not all, of our games and new app features.
